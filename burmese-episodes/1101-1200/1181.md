Chapter 1181 - Master Cloud Soul ပျောက်ဆုံးခြင်း

ဝမ်လင်သည် အရောင် (ခုနစ်) မျိုးပါသော အက်ကြောင်းထဲသို့ ဝင်ရောက်ရာတွင် သူ၏ကိုယ်ပိုင် အစီအစဉ်များ ရှိနေပြီး ၎င်းမှာ Master Ashen Pine နှင့် ပဋိပက္ခ ဖြစ်လာရန် သေချာသည်။ ဝမ်လင်သည် နိဗ္ဗာန်ခွဲခြမ်းအဆင့် အလယ်အလတ်အဆင့် ကျင့်ကြံသူတစ်ဦးကို ရင်ဆိုင်နိုင်ပြီး နောက်တစ်ယောက်သည် Master Ashen Pine နှင့် ဆက်ဆံရေး ကောင်းမွန်ခြင်း မရှိပါက နှစ်ယောက်ကိုပင် ရင်ဆိုင်နိုင်သည်!

ဝမ်လင်သည် Duanmu ဟုခေါ်သော ကလေးကို လျှို့ဝှက်စွာ စောင့်ကြည့်ခဲ့သည်။ သူသည် ရက်စက်သောသူဖြစ်ပြီး Master Ashen Pine နှင့် သူ၏ ဆက်ဆံရေးမှာ အကျိုးအမြတ်အတွက်သာ ဖြစ်သည်။

Chen Tianjun နှင့် ပတ်သက်၍မူ သူသည် Master Ashen Pine နှင့် အလွန် နီးကပ်သော ဆက်ဆံရေး မရှိပေ။ သူသည် သူ၏ကိုယ်ပိုင် အစီအစဉ်များ ရှိနေမှာ သေချာသည်။

Master Ashen Pine နှင့် အနီးကပ်ဆုံး ဆက်ဆံရေး ရှိသူ (နှစ်) ဦးသာ ရှိသည်။ ပထမတစ်ဦးမှာ Pang ဟုခေါ်သော အဘိုးအိုဖြစ်ပြီး ဒုတိယတစ်ဦးမှာ Master Cloud Soul ဖြစ်သည်။

ဝမ်လင်၏ ခွဲခြမ်းစိတ်ဖြာမှုအရ Master Cloud Soul ကြောင့်သာ Master Ashen Pine သည် လူတိုင်းကို တည်ငြိမ်စွာ ဖိတ်ကြားနိုင်ခြင်း ဖြစ်သည်။ သူတို့နှစ်ဦး ပူးပေါင်းဆောင်ရွက်ပြီး Pang ဟုခေါ်သော အဘိုးအိုကလည်း သူတို့ဘက်တွင် ရှိနေပါက ထိုအဖွဲ့သည် သူတို့ကြားတွင် မည်သူမျှ မယှဉ်နိုင်အောင် ဖြစ်နေပြီ!

ထို့ကြောင့် Master Cloud Soul ကို ဖယ်ရှားလိုက်ခြင်းသည် Master Ashen Pine ၏ လက်ရုံးတစ်ဖက်ကို ဖြတ်လိုက်ခြင်းနှင့် တူသည်။ Master Cloud Soul သည် မကောင်းသော ရည်ရွယ်ချက်များ ရှိနေပြီး အချိန်ပြည့် စောင့်ကြည့်နေသည်။ ဝမ်လင်သည် သူတို့ ပူးပေါင်းခွင့် မပေးမီ အရင်တိုက်ခိုက်ရန် ဆုံးဖြတ်လိုက်သည်။

ယခုအချိန်သည် တိုက်ခိုက်ရန် အကောင်းဆုံး အချိန်ပင်!

"နိဗ္ဗာန်ခွဲခြမ်းအဆင့် အလယ်အလတ်အဆင့်!" နိဗ္ဗာန်ခွဲခြမ်းအဆင့် အလယ်အလတ်အဆင့် ကျင့်ကြံသူကို တိုက်ခိုက်တော့မည်ကို တွေးမိရင်း ဝမ်လင် စိတ်လှုပ်ရှားနေသည်။ သူ၏ လက်ထဲရှိ သံဓားဖြင့် အားကုန် ထိုးခုတ်လိုက်သည်။

Pseudo Nirvana Void ရတနာ၏ စွမ်းအားမှာ ကောင်းကင်ကို တုန်လှုပ်စေနိုင်သည်။ ဤအချိန်တွင် ကြောက်မက်ဖွယ် ဓားစွမ်းအင်တန်းတစ်ခု Master Cloud Soul ဆီသို့ ပစ်လွှတ်လိုက်သည်။

Master Cloud Soul ၏ အမူအရာ ပြောင်းလဲသွားသည်။ သူသည် ဝမ်လင်နှင့် မလှမ်းမကမ်းတွင် ရှိပြီး အရောင် (ခုနစ်) မျိုးပါသော အက်ကြောင်းနှင့် အလွန် နီးကပ်နေသည်။ ဓားစွမ်းအင် အရှိန်ဖြင့် ရောက်ရှိလာစဉ် သူသည် တွေးချိန်ပင် မရှိတော့ပေ။ Master Cloud Soul သည် ဟိန်းဟောက်လိုက်ပြီး လက်ဖြင့် တံဆိပ်တစ်ခု ဖန်တီးလိုက်သည်။ သူ၏နောက်မှ ဝိညာဉ်မီးတောက်သည် ဝမ်လင်၏ ဓားစွမ်းအင်ကို ရင်ဆိုင်ရန်အတွက် ပျံထွက်သွားသည်။

ဝိညာဉ်မီးတောက်သည် ဝမ်လင်ဆီသို့ ပစ်လွှတ်လိုက်ပြီး ဓားစွမ်းအင်နှင့် တိုက်မိသွားသည်။ မိုးခြိမ်းသံကဲ့သို့ အသံကြီး ထွက်ပေါ်လာပြီး ဝိညာဉ်မီးတောက်မှာ ပြိုကွဲသွားသည်။ ၎င်းသည် ဓားစွမ်းအင် ထိုးဖောက်လာခြင်းကို လုံးဝ မတားဆီးနိုင်ပေ။

ဤအရေးပေါ် အချိန်တွင် Master Cloud Soul ၏ မျက်လုံးများမှာ ဒေါသဖြင့် ပြူးကျယ်သွားသည်။ ဓားစွမ်းအင် နီးကပ်လာစဉ် သူသည် လျှာဖျားကို ကိုက်လိုက်ပြီး မူလသွေးအနည်းငယ်ကို ထွေးထုတ်လိုက်သည်။ ဤသွေးသည် ဦးခေါင်းခွံတစ်ခုအဖြစ် ပြောင်းလဲသွားပြီး ဓားစွမ်းအင်တန်းကို ဝါးမြိုလိုက်သည်။

ကောင်းကင်ကို တုန်လှုပ်စေမည့် ပေါက်ကွဲသံနှင့်အတူ Master Cloud Soul ၏ ခန္ဓာကိုယ် တုန်ခါသွားပြီး သူ၏မျက်နှာမှာ ဖြူဖျော့သွားသည်။ သူ၏ မျက်လုံးထဲတွင် အံ့သြမှုများ ပြည့်နှက်နေသော်လည်း သူသည် နိဗ္ဗာန်ခွဲခြမ်းအဆင့် အလယ်အလတ်အဆင့် ကျင့်ကြံသူ ဖြစ်သည့်အတွက် ဝမ်လင်၏ ဓားစွမ်းအင်သည် သူ့ကို ပြင်းထန်စွာ မထိခိုက်နိုင်ပေ။ ထိုတိုက်မိမှုကြောင့် ဝမ်လင် နောက်သို့ ငါးလှမ်းခန့် ဆုတ်သွားရပြီး သူသည် အက်ကြောင်းထဲသို့ ပျောက်ကွယ်တော့မည် ဖြစ်သည်။

"သေချင်နေတာလား၊ ဂျူနီယာ!" Master Cloud Soul သည် ဟိန်းဟောက်လိုက်ပြီး ရှေ့သို့ ပြေးထွက်သွားသည်။ သူသည် အလွန် မြန်ဆန်ပြီး ဝမ်လင်ဆီသို့ ချက်ချင်း ရောက်ရှိလာသည်။

ဝမ်လင်မှာ သံဓား၏ အားအကောင်းဆုံး တိုက်ခိုက်မှုကို အသုံးပြုရန် အချိန် မရှိတော့ပေ။ သူ၏ မျက်လုံးထဲတွင် အေးစက်စက် အရောင်တစ်ခု လက်သွားသည်။ ဤအရာမှာ သူ မျှော်လင့်ထားသည့်အတိုင်းပင် ဖြစ်သည်။ နိဗ္ဗာန်ခွဲခြမ်းအဆင့် အလယ်အလတ်အဆင့် ကျင့်ကြံသူကို သတ်ရန် မလွယ်ကူပေ။ သူ၏ ရည်ရွယ်ချက်မှာ သူ့ကို ထိခိုက်စေရန် ဖြစ်သည်။ ဤအရာအားလုံးမှာ နောက်တစ်ဆင့်အတွက် ကြိုတင်ပြင်ဆင်ခြင်းပင် ဖြစ်သည်။

ဝမ်လင် နောက်သို့ ဆုတ်သွားပြီး အက်ကြောင်းထဲသို့ လုံးဝ ဝင်ရောက်တော့မည် ဖြစ်သည်။ Master Cloud Soul သည် အနီးကပ် လိုက်လာပြီး အက်ကြောင်းထဲသို့ ခြေတစ်လှမ်းစာ ဝင်ရောက်သွားသည်။ သူသည် လက်ကို မြှောက်ကာ အစီအရင်တစ်ခု အသုံးပြုရန် ပြင်ဆင်နေစဉ် ဝမ်လင်သည် အပြုံးတစ်ဝက်ဖြင့် ပြုံးလိုက်သည်။ သူသည် ပါးစပ်ကို ဟကာ "ရပ်!" ဟု အော်ဟစ်လိုက်သည်။

သူ၏ ခန္ဓာကိုယ်အတွင်းရှိ နတ်ဘုရား မူလစွမ်းအင်မှာ ရူးသွပ်သကဲ့သို့ တိုးဝင်လာပြီး Master Cloud Soul ကို ဝန်းရံထားသည့် ရပ်တန့်ခြင်း အစီအရင်အဖြစ် ပြောင်းလဲသွားသည်။ မျက်စိတစ်မှိတ်အတွင်းမှာပင် Master Cloud Soul ၏ ခန္ဓာကိုယ်မှာ ရပ်တန့်သွားသည်။

သူ၏ ကျင့်ကြံခြင်း အဆင့်ဖြင့် ရပ်တန့်ခြင်း အစီအရင်ကြောင့် ဖြစ်ပေါ်လာသည့် မမြင်နိုင်သော ကြိုးမျှင်များကို ချိုးဖျက်ရန် အချိန်ခဏသာ လိုအပ်သော်လည်း ၎င်းမှာ လုံလောက်သည်။ ဝမ်လင် အက်ကြောင်းထဲသို့ ဝင်ရောက်သွားချိန်တွင် ဓားစွမ်းအင်တန်းတစ်ခု Master Cloud Soul ၏ ခေါင်းဆီသို့ ပစ်လွှတ်လိုက်သည်။ ရှေးဟောင်းနတ်ဘုရား စွမ်းအားများဖြင့် ပြည့်နှက်နေသော လက်သီးချက် တစ်ခုလည်း ပစ်လွှတ်လိုက်သည်။

ဓားစွမ်းအင် နီးကပ်လာသည်။ Master Cloud Soul သည် ရပ်တန့်ခြင်း အစီအရင်မှ အချိန်မီ လွတ်မြောက်ပြီး ရှောင်တိမ်းနိုင်သော်လည်း သူသည် နာကျင်စွာ ညည်းညူလိုက်ပြီး သူ၏လက်ယာဘက်မှ သွေးများ ပန်းထွက်လာသည်။ ဓားစွမ်းအင်သည် သူ၏လက်ယာဘက်ကို ဖြတ်တောက်သွားသည်။

ဤအချိန်တွင် ရှေးဟောင်းနတ်ဘုရား လက်သီးချက် ရောက်ရှိလာသည်။ Master Cloud Soul သည် သူ၏အစီအရင်ဖြင့် ခုခံသော်လည်း သူ၏ခန္ဓာကိုယ်မှာ ဘေးသို့ အများအပြား ရွေ့လျားသွားသည်။
