# Renegade Immortal Burmese Translation Repo

ဒီ repo က **Renegade Immortal (Xian Ni)** ကို **English → Burmese** ဘာသာပြန် project အတွက်ဖြစ်ပါတယ်။

## Novel Overview (ဝတ္ထုအကျဉ်းချုပ်)

**Renegade Immortal (Xian Ni - 仙逆)** သည် နာမည်ကြီးစာရေးဆရာ Er Gen (耳根) ရေးသားထားသော Xianxia (仙侠) အမျိုးအစား Dark Fantasy / Cultivation ဝတ္ထုရှည်ကြီးဖြစ်ပါသည်။ 

**ဇာတ်လမ်းအကျဉ်း:**
Wang Lin (ဝမ်လင်း) ဟူသော ပါရမီမပါသည့် သာမန်ကောင်လေးတစ်ယောက်သည် အခွင့်အရေးတစ်ခုကြောင့် ကျင့်ကြံခြင်းလောကထဲသို့ ခြေချခွင့်ရခဲ့သည်။ သို့သော် သူ၏မိသားစုတစ်ခုလုံး ရက်ရက်စက်စက် သတ်ဖြတ်ခံလိုက်ရပြီးနောက် သူသည် ရိုးသားဖြူစင်သော ကောင်လေးတစ်ယောက်ဘဝမှ ရက်စက်ပြတ်သားသော သွေးစွန်းသည့်လမ်းစဉ် (Path of Slaughter) ကို ရွေးချယ်ခဲ့ရသည်။ "ကောင်းကင်ဘုံအလိုကို လိုက်နာလျှင် သေမျိုးသာဖြစ်မည်၊ ကောင်းကင်ဘုံကို ဆန့်ကျင်နိုင်မှသာ ထာဝရရှင်သန်သူ 'Immortal' ဖြစ်မည်" (顺为凡，逆则仙) ဆိုသည့် ဒဿနအတိုင်း ကံကြမ္မာကို ဆန့်ကျင်ကာ၊ သူချစ်ရသူ Li Muwan (လီမူဝမ်) ကို သေမင်းလက်မှ ပြန်လည်ခေါ်ယူနိုင်ရန်အတွက် စကြဝဠာကိုပါ အံတုပြီး နှစ်ထောင်ပေါင်းများစွာ ကြိုးပမ်းရုန်းကန်ရသည့် ခရီးစဉ်အကြောင်းကို ရေးဖွဲ့ထားခြင်းဖြစ်ပါသည်။

## Repo Structure

- `eng-episodes/` → English source chapters
- `burmese-episodes/` → Burmese translated chapters
- `track.md` → Progress tracking (translated count, remaining, completed files)
- `instructions.md` → Translation instructions (terminology + style + output format)
- `xian_ni_ref.md` → Comprehensive translation reference (cosmology, characters, cultivation stages, terms, etc.)

## Translation Instructions (Summary)

အသုံးပြုရမယ့် official guide က:

- `./instructions.md`
- `./xian_ni_ref.md`

အဓိက rule တွေ:

1. Cultivation ranks/terms ကို glossary အတိုင်း **တိတိကျကျ** သုံးရမယ်
2. Tone ကို serious / dark / literary style နဲ့ ထိန်းရမယ်
3. Character voice consistency ထိန်းရမယ် (ဥပမာ Wang Lin)
4. Chapter output format ကို မဖြုတ်ရ:
   - `Title: Chapter X - [Burmese Title]`
   - `Body:`
   - `Footnotes:`
